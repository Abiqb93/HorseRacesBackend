## Hard rules: no Claude speak, no Claude template layout

The user (11 November 2026: "NEVER use a Claude template format. We have my own style guide, template
and writing style. Use this. Too much Claude Speak. Too much Claude template layout. Write hard rules
to never use these."). These apply to every report, PDF, sheet, page, doc, commit message and chat reply.

Use instead (the user's two guides, 11 November 2026):
- Layout: the racing² style guide, UI Atelier's Editorial Ledger (the ui-atelier skill: its tokens.css,
  directions.md and checklist). White paper, black ink, Crimson Pro 700 titles under a 2px black rule,
  Instrument Sans for everything else, small letterspaced grey caps eyebrows, numbers set as a stat line
  (never KPI tiles), hairline table rows, first column bold, numbers right-aligned, one blue (#4A8CDC)
  that marks only the thing being pointed at, chart titles that state the finding.
- Words: the writing guide, Tom Wilson's writing style (the my-writing-style skill; register D for
  reports). "We" for racing² work, "I" for the user's own view: 27-37 first-person words per 1,000.
  Short sentences, numbers inline, lead with the result. racing² metrics capitalised: Pinhook Rating,
  Resale Rating, Breeze Rating. Run the guide's checklist before handing anything over.
- Check every finding's sign against its table before writing it: say "slips" for a negative effect,
  never "adds".

Never write (Claude speak):
- A detached narrator: a paragraph with no "we" or "I".
- Aphorisms and mic-drop lines ("Small, but it's there.", "Nothing from after the sale goes in.").
- "Not X; it's Y" pivots, spaced-dash pivots, semicolon chains.
- Signposts and scaffolding: "The market first.", "Let's dive in", "Here's the thing", "It's worth
  noting", "In short", "Bottom line", "In conclusion", "Key takeaways".
- Inflated words: genuinely, materially, crucial, robust, comprehensive, seamless, leverage, unlock,
  insights, delve, landscape, nuanced, world-class (unless the user wrote it).
- Narrating the work (11 November 2026: "Do not write like Claude. Nothing like \"we read\""): "we read",
  "we rebuilt", "it reads", "X carry the most", "works the same way", "this is hindsight, and it's why".
  Say what was found and what the user would do with it, in the phrases the writing guide quotes ("To
  evaluate we utilised a dataset of...", "As usual, we like to establish a baseline", "I had actually
  expected...", "Here's how...").
- colt and filly in lower case: always Colt and Filly (11 November 2026: "colt = Colt, filly = Filly
  everywhere").
- Generic method paragraphs ("Each foal bought at a foal sale is followed on its dam..."). Titles
  short and sharp, one line under a table at most.
- Three-item lists added for rhythm, bold-label bullets ("**Fees:** ..."), headed sections in a
  short chat reply, recaps of what was asked.

Never build (Claude template layout):
- Cream, beige or brass/gold/terracotta/navy-and-gold palettes; Georgia or default serif headings.
- Cards, boxes, tinted callouts, coloured left borders, two-up definition panels, KPI tiles.
- Boilerplate sections: "Data sources and definitions", "Methodology", "Prepared by ... UTC",
  "Every figure carries its source", source lines under report tables, "n/d" or "no data found"
  in report tables (a figure not held is a dash; the reason goes in the data sets page).
- Multi-colour charts, legends, gridlines both ways, rounded bars.
- A heading at the foot of a page with its table on the next.
